# Onboarding Defaults and Verified Configuration

Read this with `onboarding.md` for each onboarding request. Defaults are proposals, not authorization to change records.

## Defaults

- **Hourly rate:** $16 USD/hour unless the user specifies a different rate. Show the proposed rate in the approval summary; do not infer that it satisfies every assignment's pay requirements.
- **Spreadsheet display name:** Work Order Data Base.
- **Worksheet display name:** Officers.
- **Position header example:** MI, Detroit Area. This is an example, not an assignment for every hire.
- **Username suffix:** Start at 5 for compatibility with existing usernames; increment only for a confirmed different person's collision.

Resolve the spreadsheet's exact ID and worksheet's actual headers at runtime. Do not identify it by display name alone or commit employee data, private document URLs, or live column mappings to this public repository.

## Required Runtime Configuration

Obtain these from the user or approved, accessible company records. Missing required details block the relevant action rather than being guessed.

- Humanity tenant, verified activation/reset capability, and approved credential-delivery channel.
- Authorized position/site list and the approved rate.
- Exact spreadsheet ID, worksheet ID/title, actual column mapping, and permitted access.
- GSS MI Guard Guide URL and employee access confirmation.
- Adobe Sign packet status, supported by the agreement record or the user's confirmation.
- HR-approved I-9 instructions and secure document-submission route.
- Applicable payroll cycle, first-pay date and covered period, pay-stub delivery/access instructions, and direct-deposit requirements.
- Command Center/office contact and applicable Protos, WhatsApp, uniform, and armed/unarmed instructions.

## Legacy Letter Statements to Verify

The previous letter asserted a Monday-through-Sunday weekly cycle, Friday direct deposit, a first check covering two weeks, emailed pay stubs opened with the last four SSN digits, and no voided-check requirement. Keep these as verification prompts only; do not repeat them as policy without current GSS confirmation, and never collect SSN digits to prepare a letter.

Do not reuse page-based I-9 instructions from the previous letter or treat app sign-in as evidence of a handbook acknowledgment. Use approved current instructions and record acknowledgments only when actually obtained.
