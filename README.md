# Global Security Solutions Michigan

Astro site for Global Security Solutions Michigan, built for Cloudflare Workers.

## Pages

- Home: security services overview and coverage request call to action
- Services: commercial site security, patrol, event posts, documentation, and post coordination
- About: company positioning and operating approach
- Contact: placeholder contact details and coverage request guidance

## Commands

```bash
npm install
npm run dev
npm run build
npm run deploy
```

Before publishing, update the placeholder phone number and email on the contact page.
